# GUI mockups v2 (dark, 2026-11-11)

Copies of the v2 artboards from the design canvas "Himmel – GUI mockups"
(page "v2 · Dark (current)"): https://claude.ai/artifact/HvLHtroo7BhQZ5G6RJ9evE

They are design-canvas files (`.dc.html`): read them for **content and
layout**, not as production code. The spec they illustrate is
[`../../design/gui.md`](../../design/gui.md), and the hardware side is
[`../../design/hardware-mapping.md`](../../design/hardware-mapping.md).

| File | Shows |
|---|---|
| `V2Wizard1Clips.dc.html` | Wizard 1: add clips, import queue with stages and tags |
| `V2Wizard2Weapon.dc.html` | Wizard 2: Choose your weapon (cards, loadouts, touch to choose) |
| `V2Wizard3Outputs.dc.html` | Wizard 3: outputs, span / separate, source per output, latency |
| `V2Perform.dc.html` | **Perform** (MK2 + Lightpad): tallies, crossfader, layers, pads, knob strip, shuffle, outputs, weapon band |
| `V2PerformNuVJ.dc.html` | Perform adapted to the NuVJ (classic two-deck) |
| `V2Library.dc.html` | Library: mood / colour / tag filters, analysis panel, background import |
| `V2Shuffle.dc.html` | Shuffle close-up: scope, locks, history, mood map, scene bank, cues |
| `V2MK2Screens.dc.html` | The MK2 1-bit screen pages for each job |
| `V2Table.dc.html` | The VJ table (secondary view) with the room view |

Colour code: red = LIVE, green = PREVIEW, cyan = deck A, amber = deck B,
violet = shuffle / mood. Chips like `PLAY` name the hardware control.
