# GUI mockups v3 (the GUI mimics the main weapon, 2026-11-11)

Copies of the v3 artboards from the design canvas "Himmel – GUI mockups"
(page "v3 · Instrument"): https://claude.ai/artifact/HvLHtroo7BhQZ5G6RJ9evE

They are design-canvas files (`.dc.html`): read them for content and layout.
The spec is [`../../design/gui.md`](../../design/gui.md) §4 and §8, and
[`../../design/hardware-mapping.md`](../../design/hardware-mapping.md).

| File | Shows |
|---|---|
| `V3PerformMK2.dc.html` | **Perform, MAIN = MK2** (+ Block, LUMI). Interactive: click group A or F (prepare vs LIVE EDIT), the pad-mode tabs, and CANVAS 1 / 2 / 3 / 3-blend in the top strip (the monitors adapt) |
| `V3Tiles.dc.html` | Knob tiles: what turning will do, page by page |
| `V3WeaponSelect.dc.html` | Choose your weapon: one main + side arms (interactive) |
| `V3PerformNuVJ.dc.html` | Perform, MAIN = NuVJ (deck A, master, deck B, the real crossfader) |
| `V3SideArms.dc.html` | Block modes, LUMI layouts, Ohm64 and KPE1 as side arms |
| `V3MK2Map.dc.html` | MK2 cheat sheet / audience view, drawn from `weapons/mk2.weapon.json` |
| `V3Outputs.dc.html` | Set outputs: screens or projectors, 1 / 2 / 3, blend overlap, live canvas size (interactive) |
| `V3Canvas.dc.html` | One canvas, layers that snap (FILL ALL, OUT n, FIT, REPEAT, FREE), plus the text generator |
| `V3Mapping.dc.html` | Mapping for projectors: pen-tool masks, a crosshair on the real projection, Block / MK2 control |
| `V3Presets.dc.html` | Dice, mutate and rotate on every level; REC saves at the level; auto-rotate |
| `V3TwoScreens.dc.html` | One or two GUI screens: the main layout on 1, the room and side arms on 2 |
- `V3ClipPads.dc.html`: clip editor + pads (transport modes, in / out, cue points, SLICE pads, PRESS, effect levels and scope badges, variants A–D). Interactive.
