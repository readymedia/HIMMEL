Side arms: extra hands, same layout

A side arm docks as a card next to the pads. It shows what it does right now and where it acts (red = PROGRAM, green = PREVIEW). It never takes over the main weapon's job; where it has something the main lacks (a real crossfader), both work and the GUI shows both.
BLOCKdouble-tap MODE = next mode · or SHIFT+PAD MODE on the MK2
TOUCHX = effect, Y = amount, press = depth, 2nd finger = 3rd param. MODE = hold.→ PROGRAM
MIXSwipe sideways = crossfader. Top row = TAKE, bottom row = CUT.gives the MK2 a fader
LOOKS4×4 saved looks with strike velocity, while the MK2 pads stay on clips.→ PREVIEW (press harder = LIVE)
MOODTouch the map: X = calm → intense, Y = warm → cold. MODE = dice now.steers the dice
LUMIMODE = layout · OCT − / + = shift the keys
FX KEYS (default)
Left half = colour washes over program (strike = punch, pressure = depth, glide = shift hue). Right half = FX hits (strobe, stutter, kaleido, freeze …).
LOOK KEYS
Each key = a saved look, low = calm, high = peak. Play a "melody" of looks.
CLIP KEYS
Each key = a clip in the selected layer's bank (24 instead of 16).
OHM64side arm for now (could become a main later)
Faders 1–4 = preview layers A–D, faders 5–8 = program layers E–H.
Crossfader = the real crossfader (soft takeover with the MK2 wheel).
8×8 grid = 64 clips of the bank · 16 knobs = FX params of the selected layer.
KPE1 · Entrancer
Its pad = Touch FX (the same as the Block's TOUCH mode). Program keys 1–8 = 8 favourite effects. HOLD = hold. PAD MOTION = record a gesture loop on the beat. TAP/BPM = tap tempo.
Rules for every side arm
  • Its card shows its mode, its target (PROGRAM red / PREVIEW green) and live values.
  • It adds; it never remaps the main weapon.
  • Faders and crossfaders use soft takeover: they act only after they pass the current value, so nothing jumps.
  • Unplugged mid-show: the card greys out, the show goes on.
  • Any MIDI device can be a side arm with click-then-press learning.
