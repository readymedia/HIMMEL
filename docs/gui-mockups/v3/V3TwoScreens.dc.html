Rules
Screen 1 never changes because screen 2 exists. Unplug screen 2 mid-show: its panels fold back into screen 1 as cards. The GUI is one process with two windows; a crash affects neither output.
Not the show outputs
GUI screens are never show outputs. The wizard keeps them apart, so a projector can't end up showing the GUI.
