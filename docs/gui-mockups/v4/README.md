# GUI mockups v4: Playback 0.1 (current)

Design-canvas files (page "v4 · Playback 0.1" on the canvas). Read them for
content and layout only. Behaviour: `docs/design/perform.md`; GUI text:
`docs/design/gui.md` §17; build order: `docs/build-v1.md`.

- `V4PerformMK2.dc.html`: Perform with the MK2 as main. Focus (PREP green /
  PLAY red) set by the layer strips; song strip with scenes; TAKE ring and GO;
  knobs 5–8 = live macros; pads in CLIPS (scene kit with target tags), SLICE,
  SCENES, FX PADS, OUTPUTS; holding a pad lights where it lands; HIT layer;
  reset chips and the undo strip. Interactive.
- `V4PerformNuVJ.dc.html`: Perform with the NuVJ as main. The crossfader
  decides PROGRAM; wheel rings with BEND / SCRATCH / FX WHEEL (the SCRATCH
  buttons cycle them); INSTA A / B / BLACK; 3 × 3 pads per deck. Interactive.
- `V4SceneKit.dc.html`: Build › song, scene and kit editor: scenes of a song,
  layers, live macros with limits, the 16-pad kit with targets, trigger and
  PRESS per pad, "Rehearse on PREVIEW". Interactive.

v3 (`../v3/`) still holds the clip editor (`V3ClipPads`), outputs, canvas,
mapping, presets, side arms and the cheat sheet.
