# AUDIO M8: onsets, latency and input loss (2026-11-17)

Machine: the owner's dev laptop (GTX 1070, Windows 11), AUDIO agent session.
Build: `claude/audio-m8-reactions`, Release. **No renderer was run** (another
Himmel stack was running on the machine, one-stack rule); the renderer's music
path was measured with `audio_probe.exe`, which uses the engine's own
`AudioLink` + `ReactionFeed` + the FX resolver on zoom pulse at 60 Hz.

## Method

- **Line in without cables:** `himmel_audio --play-drums "CABLE Input"` plays
  the synthetic kit (`src/audio/include/himmel/audio/synth.h`: kick every beat,
  snare on 2 and 4, hats on the eighths) into the VB-Audio Virtual Cable;
  `himmel_audio --device "CABLE Output" --channels 1-2` captures the other end
  as a line in (48 kHz, WASAPI shared, event driven).
- **Loopback:** `himmel_audio --loopback "CABLE Input"` while the same drums play.
- **Real inputs opened:** BLUE USB mic, Realtek mic array, Focusrite
  "Analogue 1 + 2" (nothing connected) — opened, metered, gated in a quiet room.
- **Input loss:** the capture process was killed after 12 s and started again
  4 s later while `audio_probe` and the drums kept running.

## Results

| Check | Result |
|---|---|
| Cable line in, 120 BPM, 24 s | 48 kicks (all), snares on 2 / 4, hats on the off-beats |
| Cable line in, 128 BPM, 16 s (twice) | 35 kicks, 17 / 19 snares, 52 / 53 hats |
| Loopback, 120 BPM, 12 s | 24 kicks |
| Signal age when a 60 Hz "frame" saw a kick | median 7–10 ms, worst 17 ms (includes up to one frame of sampling) |
| Kill himmel_audio | "no audio" after 0.33 s (250 ms heartbeat timeout), reactions glide to rest |
| Start it again | signals back within ~0.7 s of the start (device open + first hop) |
| A second himmel_audio | refuses to start ("another himmel_audio is running") |
| Quiet room mic / unconnected line in | −68 dBFS, gated (level 0, no onsets) |
| Offline (`audio_tests`): onset latency | kick detected 5–10 ms after the hit (one or two 5 ms hops), snare one hop later |
